# Para mi papita 💛

Página web estática con temática de **flores amarillas** y una estética inspirada en **Los diarios de la boticaria**.

## Archivos

- `index.html` — contenido principal
- `styles.css` — diseño, flores y animaciones
- `script.js` — interacción y pétalos animados

## Cómo publicarla gratis con GitHub Pages

1. Entra a GitHub y crea un repositorio nuevo.
2. Puedes llamarlo, por ejemplo: `para-mi-papita`.
3. Sube los tres archivos de esta carpeta:
   - `index.html`
   - `styles.css`
   - `script.js`
4. En el repositorio entra a:
   **Settings → Pages**
5. En **Build and deployment**, selecciona:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/ (root)`
6. Guarda los cambios.
7. GitHub te mostrará la URL pública de la página.

La dirección normalmente se verá así:

`https://TU-USUARIO.github.io/para-mi-papita/`

## Cómo cambiar el mensaje

Abre `index.html` y busca la sección:

```html
<section class="section message-section" id="mensaje">
```

Dentro encontrarás la carta completa. Puedes reemplazar el texto por el tuyo.

## Cómo cambiar "tu persona"

Busca:

```html
<span>tu persona 💛</span>
```

y cámbialo por tu nombre, apodo o firma.

## Importante

El diseño usa ilustraciones hechas con HTML/CSS y emojis; no incluye imágenes oficiales ni material visual extraído del anime, para que puedas publicarlo directamente.
